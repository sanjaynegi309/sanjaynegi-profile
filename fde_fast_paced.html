Frequently Asked Questions

Clear answers before you commit.

Is 8+ years of experience mandatory?
No. Eight or more years is the suggested audience, not a strict eligibility requirement. Engineers with less experience can join if they have strong coding skills and software engineering fundamentals.
Do I need prior AI or ML experience?
Deep AI or ML experience is not required. You should already be comfortable with programming, APIs, debugging and application development. The course is not intended for programming beginners.
What programming language will be used?
Python is the common implementation language. Experience in Java, C#, TypeScript, C++, Kotlin or another established language is a suitable starting point, but you must be prepared to write Python during the program.
Will we learn LangChain, LangGraph and OpenAI Agents SDK?
Yes. LangChain, LangGraph, LangSmith and OpenAI Agents SDK are part of the core learning path. You'll learn their engineering use cases, implementation patterns and trade-offs rather than only their APIs.
Will Docker, AWS and CI/CD be covered?
Yes. The core deployment path uses Docker, GitHub Actions and AWS ECS Fargate, with production monitoring and secrets management. Kubernetes and advanced MLOps topics are optional extensions during project mentorship.
Will we cover Hugging Face, Ollama and OpenRouter?
These are included as advanced ecosystem topics and may be used during mentorship projects. They are not taught at the same depth as the core frameworks.
What happens during the six-month mentorship?
You'll work on progressively challenging enterprise AI projects, with fortnightly implementation clinics, architecture discussions, code feedback and iterative improvements. The emphasis is on building independently with guidance.
How much time should I commit?
The intensive has six hours of core classes each week, plus optional Saturday office hours. Plan for approximately 3–5 additional hours of independent practice and assignments. The mentorship phase requires consistent project work between clinics.
Will I become a Forward Deployed Engineer after this course?
The program is designed to develop the engineering and delivery capabilities associated with FDE work. Actual role readiness also depends on your implementation quality, customer-facing experience and the requirements of individual employers. No job or placement is guaranteed.
What if I miss a live class?
Session recordings are included to help you catch up. Live attendance is strongly recommended for hands-on implementation, discussions and feedback.
Are additional cloud or model API charges included?
Some exercises may require access to paid model APIs or cloud services. Any such usage charges are separate unless explicitly included in the registration offer. Cost-controlled configurations will be preferred wherever practical.
